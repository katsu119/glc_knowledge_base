## 阶段执行计划

### Phase 1: 框架 + 用户空间层
- 创建 standalone TikZ 文件
- 定义全部样式（颜色、尺寸、字体）
- 绘制左栏：用户空间层（应用程序、C库、守护进程）
- 绘制系统调用接口（syscall dispatch）
- 绘制右栏对应细节 A/B

### Phase 2: 内核核心 - 进程 + 内存
- 左栏：调度器、进程管理、内存管理概览块
- 右栏：调度器内部结构详图
- 右栏：进程管理内部结构（task_struct, fork, namespaces）
- 右栏：内存管理内部结构（buddy, slab, VMA, swap）

### Phase 3: 内核 I/O - VFS + 网络 + 设备
- 左栏：VFS/文件系统、网络协议栈、设备驱动概览块
- 右栏：VFS 内部 + 块层 + 具体文件系统
- 右栏：网络协议栈内部（socket → TCP → IP → netfilter）

### Phase 4: 内核基础设施 + 体系结构
- 左栏：IPC、中断、同步、时间管理、体系结构概览块
- 右栏：中断子系统内部、IPC 机制细节、同步原语、时间子系统
- 右栏：体系结构细节（x86 页表/启动）

### Phase 5: 硬件层 + 全局连线
- 左栏：硬件层
- 全局数据流箭头
- 颜色美化、布局微调
- 编译 → 发送 PDF
