\begin{personalnote}
\textbf{关于 CIC 滤波器的核心技术要点}

CIC（Cascaded Integrator-Comb）滤波器是一种高效的数字滤波器，广泛应用于通信系统中的抽取/插值操作。核心要点如下：

\begin{enumerate}
  \item \textbf{基本结构}：由积分器（Integrator）和梳状滤波器（Comb）级联而成。积分器工作在高采样率端，梳状滤波器工作在低采样率端，中间通过抽取/插值器连接。
  \item \textbf{数学原理}：CIC 滤波器的冲激响应可视为多个矩形窗的卷积。频率响应具有 $\mathrm{sinc}$ 函数形状，零点位于 $f = k \cdot f_s / R$（$k=1,2,\\ldots,R-1$），其中 $R$ 为抽取/插值因子。
  \item \textbf{核心优势}：\textbf{无需乘法器}——仅使用加法器和寄存器即可实现，资源消耗极低，非常适合 FPGA 实现。代价是通带衰减较大，通常需要在后端加 FIR 补偿滤波器（CIC 补偿滤波器）。
  \item \textbf{设计参数}：$R$（抽取/插值比）、$N$（级数）、$M$（差分延迟，通常取 1 或 2）。级数 $N$ 决定了阻带衰减和通带滚降的陡峭程度。
  \item \textbf{寄存器位宽}：内部寄存器位宽需满足 $B_{\text{max}} = B_{\text{in}} + N \log_2 (RM)$ 以避免溢出，这是设计中容易忽略的关键细节。
\end{enumerate}

\end{personalnote}

\begin{personalnote}
\textbf{CIC 建模验证详细规划（与 agent 交互后的反思）}

CIC 验证的思路是以 Python 理论模型作为参考设计，后续用于 RTL 的 reference model。具体分以下四步：

\begin{enumerate}
  \item \textbf{验证 DSM 信号的生成}：给出对应的输入（如 sine 波形），观察内部累加器以及输出 1bit 流的对应波形，确认 DSM 行为正确。
  \item \textbf{设计 CIC 滤波器模型}：给一个固定信号，观察滤波结果是否正确，同样需要绘制波形进行验证。
  \item \textbf{时频域分析}：将测试波形输入到 CIC，分析对应的时频域波形以及相应的内部信号，观察是否符合要求的性能参数（如通带纹波、阻带衰减等）。
  \item \textbf{生成参考波形}：生成 input 和 output 参考波形，供 RTL 进行参考验证（作为 golden reference）。
\end{enumerate}

\textbf{经验反思}：驾驭 agent 时，不能给的要求太笼统，否则生成又多又没用的代码。最好给出具体的功能要求——分步骤、明确输入输出、清晰验证标准。这样 agent 产出的代码才可直接利用。

\end{personalnote}
