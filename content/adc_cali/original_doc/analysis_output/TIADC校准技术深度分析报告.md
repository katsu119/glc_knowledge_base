## 1. 绪论：时间交织ADC的前世今生

### 1.1 为什么需要TIADC？

在现代电子系统中，ADC（模数转换器）是连接模拟世界与数字世界的桥梁。随着5G/6G通信、高速示波器、雷达系统和电子战技术的发展，对ADC采样率的要求已从 **GSa/s（千兆采样/秒）** 迈向 **数十GSa/s**。

然而，单个ADC的采样率受限于：
- **工艺限制**: CMOS工艺的晶体管特征频率有限
- **功耗限制**: 高速ADC的功耗随采样率超线性增长
- **精度限制**: 高精度（高位宽）与高速度之间存在根本性矛盾

**时间交织ADC (TIADC)** 应运而生——它通过M个低速率子ADC并行工作，在不牺牲精度的前提下成倍提升采样率。

### 1.2 本项目中的TIADC系统

本项目研究了两套TIADC系统：

| 系统 | 通道数 | 采样率 | 应用场景 |
|------|--------|--------|---------|
| **16通道系统** | 16路 | 16 GSa/s | 中速高精度 |
| **64通道系统** | 64路 | 64 GSa/s | 超高速采样 |

核心设计思路如下图所示：

```
模拟输入 Vin(t)
    │
    ▼
┌──────────────────────────────────────────┐
│              时钟分配网络                   │
│  ┌──┐  ┌──┐  ┌──┐          ┌──┐         │
│  │φ1│  │φ2│  │φ3│    ...   │φM│         │
│  └┬─┘  └┬─┘  └┬─┘          └┬─┘         │
│   │     │     │             │           │
│   ▼     ▼     ▼             ▼           │
│ ┌───┐ ┌───┐ ┌───┐       ┌───┐         │
│ │CH1│ │CH2│ │CH3│  ...  │CHM│         │
│ └───┘ └───┘ └───┘       └───┘         │
│   采样时刻依次错开 T=1/fs               │
└──────────────────────────────────────────┘
    │
    ▼
  数字输出 (MUX合并)
```

> **关键洞察**: 时间交织的核心在于——每个子ADC以 `fs/M` 的速率采样，但采样时钟相位依次错开 `T = 1/fs`。结果，整体采样率等效为 `fs`，是单个子ADC的M倍。

### 1.3 失配问题——理想与现实的差距

理论上，M个完全一致的子ADC并行工作就能实现完美的M倍采样率提升。但现实中的芯片制造存在 **工艺偏差(Process Variation)** ，导致各通道之间存在三种失配：

1. **失调失配 (Offset Mismatch)** —— 各通道直流偏置不同
2. **增益失配 (Gain Mismatch)** —— 各通道放大倍数不同
3. **时钟偏斜失配 (Timing Skew Mismatch)** —— 各通道采样时刻偏离理想位置

**如果不校准，TIADC的动态性能甚至不如单个子ADC。**

> **一个形象的比喻**: 想象M个人排成一排传递水桶。如果每个人的身高（失调）、臂力（增益）和出手时机（时钟偏斜）都不一样，那么整个传递链条的效率会大打折扣。校准就是要让所有人的动作协调一致。

## 2. TIADC的三种失配误差：从理论到现象

### 2.1 失调失配 (Offset Mismatch)

#### 物理本质

每个子ADC内部都有输入偏置电压（由比较器失调、电荷注入等引起）。即使是完全相同的版图设计，制造完成后每个通道的偏置电压也会略有不同。

#### 数学描述

第k通道的输出可表示为：
$$y_k[n] = x_k[n] + O_k$$

其中 $O_k$ 为第k通道的失调误差，$x_k[n]$ 为理想采样值。

#### 频谱影响

失调失配在频域引入位于 **$f_s/M$ 及其整数倍** 处的杂散(spur)：

$$f_{\text{spur}} = k \cdot \frac{f_s}{M}, \quad k = 0, 1, 2, \ldots, M-1$$

这些杂散与输入信号频率无关——它们是**固定图案噪声**。

> **代码中的体现** (`offset_8bits_not2.m`):
> ```matlab
> offset_mismatch=[0.00216855990585554, -0.0129542156382229, ...];
> % 这些值代表每个通道的直流偏移量（归一化后）
> Vi(16*(i-1)+r,1) = 0.6*cos(2*pi*fin1*(...)) + offset_mismatch(r);
> ```
> 可以看到，每个通道的输入信号被叠加了一个固定的偏移量。

### 2.2 增益失配 (Gain Mismatch)

#### 物理本质

各通道ADC的参考电压、电容阵列匹配程度不同，导致对同一输入信号的增益（放大倍数）不同。

#### 数学描述

第k通道的输出可表示为：
$$y_k[n] = (1 + \Delta G_k) \cdot x_k[n]$$

其中 $\Delta G_k$ 为第k通道的增益误差。

#### 频谱影响

增益失配同样会在 $f_s/M$ 及其整数倍处引入杂散，但与失调失配不同的是：
- **杂散幅度与输入信号幅度成正比**
- 输入信号越大，增益失配的影响越严重

> **代码中的体现** (`gain_8bits_not2.m`):
> ```matlab
> gain_mismatch(i) = 1+randn(1,1) * 0.01;  % 随机生成±1%的增益误差
> gain_mismatch=[1.02, 1.0313, 0.9546, ...]; % 实际使用的增益值
> Vi = (1+F4*step_size)*gain_mismatch(r)*0.4*cos(...) + offset_mismatch(r);
> ```
> 注意 `(1+F4*step_size)` 就是增益补偿系数 $g'_i$，而 `gain_mismatch(r)` 是原始增益误差。

### 2.3 时钟偏斜失配 (Timing Skew Mismatch)

#### 物理本质

时钟分配网络的不理想导致每个子ADC的采样时钟边沿相位不能精确地间隔 $T_s$。时钟偏移包括：
- **时钟延时 (Clock Delay)**: 固定的相位偏移，**可以被校准** ✅
- **时钟抖动 (Clock Jitter)**: 随机的相位噪声，**无法被校准** ❌

#### 为什么时钟偏斜最棘手？

时钟偏斜引入的误差幅度 **与输入信号频率成正比**：

$$\epsilon_k \approx A \cdot 2\pi f_{in} \cdot \Delta t_k \cdot \cos(2\pi f_{in} t_k)$$

这意味着：
- 对于低频信号，误差很小，可以忽略
- 对于高频信号（接近奈奎斯特频率），微小的时钟偏差会导致巨大的采样误差
- 这是限制TIADC在高频应用中的**最主要瓶颈**

> **代码中的体现** (`time_not2.m`):
> ```matlab
> skew_mismatch=[0.5*10^-12, -1.7*10^-12, 2.8*10^-12, -2.5*10^-12];
> % 单位: 皮秒(picosecond)!
> % 64GHz采样时，理想间隔 T = 1/64GHz ≈ 15.6ps
> % 这里的时间偏斜只有0.5~2.8ps，但已足以严重劣化性能
> ```

### 2.4 三种失配的对比总结

| 特性 | 失调失配 | 增益失配 | 时钟偏斜失配 |
|------|---------|---------|------------|
| **物理根源** | 偏置电压不匹配 | 参考电压/器件不匹配 | 时钟分配不匹配 |
| **数学形式** | 加法性误差 $+O_k$ | 乘法性误差 $\times G_k$ | 时间位移 $\Delta t_k$ |
| **杂散位置** | $f_s/M$ 整数倍 | $f_s/M$ 整数倍 | $f_s/M$ 整数倍 |
| **与输入频率关系** | 无关 | 正比于信号幅度 | **正比于信号频率** |
| **随时间变化** | 基本稳定 | 基本稳定 | 基本稳定（仅延时部分）|
| **校准难度** | ⭐⭐ 中等 | ⭐⭐ 中等 | ⭐⭐⭐ 最难 |
| **校准顺序** | 第1步 | 第2步 | 第3步 |

## 3. ADC行为模型：校准算法的试验场

在实际芯片流片（制造）之前，我们需要用 **MATLAB行为模型** 来验证校准算法。本项目提供了多种ADC行为模型，每种模型模拟不同的ADC架构。

### 3.1 非二进制(冗余) SAR ADC 模型 — `ADCF.m`

#### 什么是非二进制ADC？

传统二进制SAR ADC每一位的权重是2的幂次（如128, 64, 32, 16, 8, 4, 2, 1）。而非二进制ADC采用 **冗余权重** 设计——权重之和大于满量程范围，给比较器判决留出了纠错空间。

#### 模型详解

```matlab
function [out]=ADCF(in)
    Vn = 0.45 + in/2;
    Vp = 0.45 - in/2;
    % 归一化到 0~256 范围
    Vn = Vn / 0.9 * 256;
    Vp = Vp / 0.9 * 256;
    
    % 非二进制权重序列
    r = [60, 28, 16, 10, 6, 4, 2, 1, 0.5];
    
    % 9次逐次逼近比较
    % 每次比较Vn和Vp的大小，输出1位判决结果
    % 输出码字权重 = [120, 56, 32, 20, 12, 8, 4, 2, 1]
end
```

**工作原理解析**（类比天平称重）：

1. **初始化**: 将输入信号分配到两个比较节点 Vp（正端）和 Vn（负端）
2. **逐位比较**: 从最高位（权重60）开始，判断 Vn ≥ Vp？
   - 如果 Vn ≥ Vp → 该位输出1，**Vn减去权重，Vp加上权重**（相当于天平一端减砝码，另一端加砝码）
   - 如果 Vn < Vp → 该位输出0，**Vn加上权重，Vp减去权重**
3. **输出合成**: 将9位判决结果乘以对应权重后求和

**关键洞察**: 非二进制ADC的核心优势在于——由于权重之和(60+28+16+10+6+4+2+1+0.5=127.5)大于满量程范围(128)，比较器在前面的判决即使出错，后续位还能"纠回来"。而二进制ADC一旦高位判决错误，误差无法挽回。

#### PDF文档中的对应

在 `gain_loop.pdf`（实际文档中多次引用`ADCF`函数）和 `time_skew__ (13).pdf` 中反复使用 `ADCF(Vi)-128` 来模拟ADC量化过程。这是整个校准算法验证的基础。

### 3.2 二进制 SAR ADC 模型 — `ADCF_2.m`

#### 模型详解

```matlab
function [out]=ADCF_2(in, n, FS, os)
    % n: 量化位数
    % FS: 满量程范围
    % os: 失调偏移
    for i = 1:n
        if (input >= FS/2^i - FS/2^(n+1))
            output = FS/2^i + output;
            input = input - FS/2^i;
        end
    end
    out = output + os;
end
```

**工作原理**：从MSB到LSB，依次判断输入是否大于当前位的阈值（`FS/2^i - FS/2^(n+1)`，即减去半LSB的偏移以实现四舍五入量化），如果是则将该位的权重加入输出并从输入中减去该权重。

例如8位ADC的判断阈值依次为:
`FS/2, FS/4, FS/8, FS/16, FS/32, FS/64, FS/128, FS/256`

**与 `ADCF.m` 的对比**:

| 特性 | ADCF.m (非二进制) | ADCF_2.m (二进制) |
|------|-------------------|-------------------|
| 权重序列 | [60,28,16,10,6,4,2,1,0.5] | 标准的2的幂次 |
| 输出码字权重 | [120,56,32,20,12,8,4,2,1] | 标准的二进制 |
| 冗余度 | 有（权重和>范围） | 无 |
| 适用场景 | `time_not2.m` (非二进制ADC校准) | `time_not2_1.m` (二进制ADC校准) |

### 3.3 二进制差分 ADC 模型 — `ADCF_Binary.m`

这是一个差分输入的双端ADC模型，更接近真实的模拟全差分SAR ADC架构。其输出为8位二进制码：

## 4. 第一步：Offset校准原理与实现

### 4.1 核心原理

**基本思想**: 对正弦信号大量采样，理论上均值为0。但由于存在失调偏移，均值不为0——这个均值就是失调误差的估计值。

#### 算术平均法（公式1）

$$\bar{x}(n) = \frac{1}{N} \sum_{k=0}^{N-1} x(n-k)$$

这种方法需要N个存储单元和周期性的清零控制信号，存在两个问题：
1. 输出不连续，每N个点才更新一次
2. 输出可能发生突变，不平滑

#### 指数平均法（公式2）—— 本项目采用的方法

$$\bar{x}(n) = \bar{x}(n-1) + \alpha [x(n) - \bar{x}(n-1)]$$

这实际上是一个**一阶IIR低通滤波器**，具有以下优点：
- 输出连续，每次采样都更新
- 平滑度高，没有突变
- 硬件实现简单（只需一个加法器+移位寄存器，无需乘法器）

### 4.2 Verilog代码中的实现（根据PDF文档）

```verilog
int_nxt(n+1) = int_nxt(n) + α[data_shift(n) − offset(n)]
```

其中：
- `int_nxt`: 存储offset迭代估计值（29位宽）
- `α`: 迭代步长/带宽，控制收敛速度和精度
- `data_shift`: ADC采样数据扩展4位（增加小数精度）
- `offset`: 截取 `int_nxt[28:21]` 作为最终offset值（8位）

### 4.3 MATLAB代码实现分析 (`offset_8bits_not2.m`)

```matlab
% 核心迭代循环
for i = 1:j-1
    for r = 1:M   % M=16通道
        % 生成带失调误差的输入信号
        Vi = 0.6*cos(2*pi*fin1*t) + offset_mismatch(r);
        
        % ADC量化
        Ao(i,r) = ADCF(Vi) - 128;
        
        % 指数平均迭代
        int(r,i+1) = int(r,i) + w(1) * Ao(i,r);
        
        % 截取整数部分（模拟硬件中的位宽限制）
        int_limit(r,i+1) = floor(int(r,i+1) * 4) / 4;
    end
end
```

**收敛判断机制**（代码中的 `up_down` 逻辑）:
```matlab
% 监测offset估计值的变化方向
if int_limit(t,i+1) > int_0
    up_down(s,1) = 1;      % 增大
elseif int_limit(t,i+1) < int_0
    up_down(s,1) = 0;      % 减小
end
% 统计变化方向，判断是否收敛
sum_1 = sum(up_down);  % 增大的次数
sum_0 = 2 - sum_1;     % 减小的次数
% 当增大和减小的次数相等时，认为收敛
```

> **代码-文档对照分析**:
> - PDF文档中的 `α = 2⁻¹⁰, 2⁻¹², …, 2⁻²¹` 共8个档位
> - **代码中实际只使用了 `w = [2⁻¹⁰, 2⁻¹¹, 2⁻¹², 2⁻¹³, 2⁻¹⁴, 2⁻¹⁵]` 共6个档位**
> - 代码中未实现完整的档位自动切换逻辑（仅使用了 `w(1)`），这是一个简化的行为级验证

### 4.4 溢出保护

由于硬件寄存器位宽有限，offset估计值可能溢出。PDF文档和代码共同说明了溢出检测逻辑：

```
正常:    0 111 1111  (正的最大值)
上溢:    1 000 0000  (变为负数!) → 需要饱和到 0 111 1111
下溢:    1 000 0000 → 0 111 1111 (变为正数!) → 需要饱和到 1 000 0000
```

**溢出检测方法**（通过符号位判断）:
```verilog
overflow_pos = ~int[28] & ~data_sub[15] & acc[28];
overflow_neg = int[28] & data_sub[15] & ~acc[28];
```

## 5. 第二步：Gain校准原理与实现

### 5.1 核心原理

**基本思想**: 增益校准的目标不是消除每个通道的绝对增益误差，而是**消除通道间的相对增益误差**——即让所有通道的增益相等。

#### 为什么消除相对误差就够了？

因为通道间增益误差的影响可被看作**幅度调制(AM)过程**——输入信号被周期性的增益误差序列幅度调制。如果所有通道的增益一致（即使不是1），数据只是被整体放大或缩小，不会产生杂散。

#### 数学表达

假设16路通道的增益误差分别为 $g_1, g_2, ..., g_{16}$，引入增益补偿系数 $g'_1, g'_2, ..., g'_{16}$ 后，需要满足：

$$1 + g_1 + g'_1 = 1 + g_2 + g'_2 = \cdots = 1 + g_{16} + g'_{16}$$

即所有通道经过补偿后的增益相等。

### 5.2 LMS迭代算法

增益校准的核心是**LMS（最小均方）迭代算法**，通过比较各通道输出信号的**平均功率**与**参考功率（阈值Th）** 来调整增益补偿系数：

$$g'_i[n+1] = g'_i[n] + \alpha (Th[n] - y_i[n]^2)$$

#### 工作原理

1. 计算第i通道输出信号的瞬时功率：$y_i[n]^2$
2. 与参考值 Th 比较：
   - 如果 $y_i[n]^2 > Th$ → 减小增益补偿系数
   - 如果 $y_i[n]^2 < Th$ → 增大增益补偿系数
3. 当各通道输出功率都收敛到 Th 时，相对增益误差被消除

#### 为什么收敛后公式成立？

当增益补偿系数收敛后，$g'_i[N+n-1] - g'_i[N] = 0$，代入迭代公式可得：

$$\frac{y_i[N]^2 + y_i[N+1]^2 + \cdots + y_i[N+n-1]^2}{n} = Th$$

即每个通道输出信号的平均功率都等于Th，因此所有通道的平均功率相等。

### 5.3 参考值选取的两种模式

| 模式 | 描述 | 代码中的实现 |
|------|------|-------------|
| **模式0** | 以通道1的瞬时功率为参考 | `th = F1(1,:)`（通道1的输出功率） |
| **模式1** | 以16通道瞬时功率均值为参考 | `th = sum(F1(1:M,:))/16`（平均功率） |

`gain_8bits_not2.m` 中默认使用**模式1**（以平均值为参考）：
```matlab
th_fl(1,i) = round(th(1,i)/16);          % 计算16通道平均值
F3(r,i+1) = F3(r,i) - beta*(F1(r,i+1) - th_fl(1,i));  % LMS迭代
```

### 5.4 MATLAB代码实现分析 (`gain_8bits_not2.m`)

```matlab
beta = 1/2^26;        % 带宽控制，相当于α
step_size = 0.05/31;  % 增益补偿系数步长（6位控制字）

for i = 1:j-1
    for r = 1:M
        % 应用增益补偿: (1+F4*step_size)
        Vi = (1+F4(r,i)*step_size) * gain_mismatch(r) * 0.4*cos(...) + 0.45;
        
        % ADC量化
        Ao(i,r) = ADCF_2(Vi, 8, 0.9, 0) * 256 - 128;
        
        % 计算瞬时功率
        F1(r,i+1) = Ao(i,r) * Ao(i,r);
        
        % LMS迭代: F3存储累积值
        F3(r,i+1) = F3(r,i) - beta * (F1(r,i+1) - th_fl(1,i));
        
        % 提取增益补偿系数（截取前几位）
        F4(r,i+1) = floor(F3(r,i+1) * 512);
    end
end
```

**代码-文档对照分析**:

| PDF文档中的描述 | 代码中的实现 | 说明 |
|----------------|-------------|------|
| `α = 2⁻³²~2⁻³⁹` 共8档 | `beta = 1/2²⁶` 单档位 | 代码简化，只验证概念 |
| `f4` 位宽9位 | `F4 = floor(F3*512)` | 512=2⁹，提取前9位 |
| 增益补偿系数范围±3% | `step_size = 0.05/31` | 6位控制字，32级，每级0.05% |
| Leaky积分器低通滤波 | 使用指数平均 | 文档中有图9说明，代码未显式实现 |

## 6. 第三步：Timing Skew校准原理与实现

### 6.1 核心原理 —— 基于自相关算法

**这是三种校准中最复杂、也最精妙的一种。**

#### 从2路交织开始理解

考虑2路交织ADC，通道1为参考（理想），通道2存在时间偏斜 $\Delta T$：

```
通道1采样:  ...  y1[k-1]        y1[k]
                     │            │
                     ▼            ▼
时间轴:  ─────●──────────●──────────●──────>
             y1[k-1]    y2[k-1]    y1[k]
                         │
                     通道2采样
                     (有偏移 ΔT)
```

**关键观察**: 如果通道2的采样时刻偏左（$\Delta T < 0$），则 `y1[k-1]` 与 `y2[k-1]` 的相关性增强；如果偏右，则 `y2[k-1]` 与 `y1[k]` 的相关性增强。

#### 数学化表达

自相关差值：
$$D_{\Delta t} = R_x(T_{ck} - \Delta T) - R_x(T_{ck} + \Delta T)$$

利用自相关函数的偶函数特性：
$$D_{\Delta t} = R_x(T_{ck} - \Delta T) - R_x(T_{ck} + \Delta T)$$

当 $\Delta T$ 足够小时，用泰勒展开：
$$D_{\Delta t} = -2\Delta T \left.\frac{dR_x}{d\tau}\right|_{\tau=T_{ck}}$$

**结论**: $D_{\Delta t}$ 的符号指示了偏移方向，大小指示了偏移程度。

### 6.2 从2路扩展到16/64路

在`time_not2.m`中，64通道系统被组织为4组16通道，每组由同一个16GHz时钟驱动：

```
时钟组1 (φ1): 通道 1, 5, 9, 13, ..., 61  (mod 4 == 1)
时钟组2 (φ2): 通道 2, 6, 10, 14, ..., 62  (mod 4 == 2)
时钟组3 (φ3): 通道 3, 7, 11, 15, ..., 63  (mod 4 == 3)
时钟组4 (φ4): 通道 4, 8, 12, 16, ..., 64  (mod 4 == 0)
```

> 由于4组时钟共享同一时钟源，只需校准4个时钟偏斜参数（$\Delta t_2, \Delta t_3, \Delta t_4$），通道1为参考。

### 6.3 MATLAB代码实现分析 (`time_not2.m`)

```matlab
% 自相关计算: 相邻通道采样值相乘后累加
for i = 1:N/64-1
    for t = 1:64
        % 生成带时间偏斜的输入信号
        if mod(t,4) == 0      % 组4
            Vi = cos(2πf(t + skew(4) - mismatch_1(i,4)*step_size));
        elseif mod(t,4) == 1  % 组1 (参考)
            Vi = cos(2πf(t + skew(1)));
        else                  % 组2, 3
            Vi = cos(2πf(t + skew(mod(t,4)) - mismatch_1(i,mod(t,4))*step_size));
        end
        Ao(i,t) = ADCF(Vi) - 128;
    end
    
    % 计算64个通道两两相邻的自相关之和
    % A1 = Ao(64)*Ao(1) + Ao(1)*Ao(2) + Ao(2)*Ao(3) + Ao(3)*Ao(4)  (组间+组内)
    % A2 = Ao(4)*Ao(5) + Ao(5)*Ao(6) + Ao(6)*Ao(7) + Ao(7)*Ao(8)
    % ... (共16组 A1~A16)
    A17 = A1 + A2 + ... + A16;  % 总自相关和
    
    % 计算每个非参考通道的误差
    for t = 2:4
        % 该通道组在所有16组位置的自相关和
        e(i,t) = -Σfloor(Ao(t-1+(m-1)*4) * Ao(t+(m-1)*4) / s) * 4;
        % 与平均自相关比较，得到误差方向
        e(i,t) = floor((e(i,t) + A17) / h);
        
        % LMS迭代更新时间补偿参数
        mismatch(i+1,t) = mismatch(i,t) + u * e(i,t);
        mismatch_1(i+1,t) = floor(mismatch(i+1,t) / 2^24);
    end
end
```

**核心算法流程**:

```
对于每次迭代 i:
  1. 采集64通道数据
  2. 计算所有相邻通道的自相关 A1~A16
  3. 计算总平均自相关 A17
  4. 对于通道组 t=2,3,4:
     a. 计算该通道组在所有16个位置的局部自相关
     b. 与平均值比较 → 得到误差方向 e
     c. LMS更新: mismatch += u * e
     d. 截取高24位作为控制字 mismatch_1
  5. 用控制字调整时钟延迟 → 影响下次采样的时间偏斜
```

### 6.4 代码中的多种实现变体

本项目有多个时序校准的实现版本，体现了算法设计的迭代过程：

| 文件 | 通道数 | ADC类型 | 特点 |
|------|--------|---------|------|
| `time_loop.m` | 16 | 通用ADC | 迭代步长 `u=2⁻⁷⁰`（极小），收敛极慢但精度高 |
| `time_not2.m` | 64 | 非二进制(ADCF) | 仅含时间校准，4组时钟 |
| `time_not2_1.m` | 64 | 二进制(ADCF_2) | 二进制ADC版本，带直流偏置 |
| `time_onlyone.m` | 64 | 非二进制 | 只校准3个时钟组（简化为8通道相关），无偏移 |
| `all_cali.m` | 64 | 两者皆支持 | **最完整版本**，同时包含offset+gain+time skew |

### 6.5 time_loop.m 实现的独特思路

`time_loop.m` 采用了不同的实现策略：迭代步长极小（`u=2⁻⁷⁰`），这意味着收敛需要非常多的迭代次数，但收敛后的抖动也极小。

另一个显著特点是它使用**相邻通道相关值与平均值的差**作为误差信号：
```matlab
% 计算所有通道的自相关均值
s = sum(Avg_I(:,i));
avg = s / 16;
% 每个通道与均值比较
error(k+1, i+1) = Avg_I(k,i) - avg;
```

这与 `time_not2.m` 中只校准3个非参考时钟组的方式形成对比。

## 7. 综合校准：三管齐下

### 7.1 `all_cali.m` —— 完整的校准流水线

`all_cali.m` 是项目中最综合的校准脚本，它在一次仿真中同时实现了：
1. **Offset校准**: 指数平均法估计并消除直流偏移
2. **Gain校准**: LMS迭代使各通道功率相等
3. **Timing Skew校准**: 自相关法校准时钟偏斜

#### 代码中的三重校准嵌套

```matlab
for i = 1:N/64-1
    for t = 1:64
        % 1. 生成带所有误差的输入信号（offset + gain + timing skew）
        Vi(i,t) = (1+gain_f4(t,i)*gain_step_size) * gain_mismatch(1,t) * ...
                  0.8 * cos(2π*fin1*(T*((i-1)*64+t) + skew - mismatch_1*step_size)) + ...
                  offset_mismatch(1,t) - int_limit(t,i)/256;
        
        Ao(i,t) = ADCF(Vi(i,t)) - 128;
        
        % 2. Gain校准
        gain_f1(t,i+1) = Ao(i,t)^2;           % 瞬时功率
        gain_f3(t,i+1) = gain_f3(t,i) - beta * (gain_f1(i+1) - th_fl);
        gain_f4(t,i+1) = floor(gain_f3 * 512); % 增益补偿系数
        
        % 3. Offset校准
        int(t,i+1) = int(t,i) + w(1)*Ao(i,t);
        int_limit(t,i+1) = floor(int(t,i+1)*4)/4;
    end
    
    % 4. Timing Skew校准（自相关法）
    % ...计算A1~A16, A17...
    for t = 2:4
        e(i,t) = ...  % 计算误差方向
        mismatch(i+1,t) = mismatch(i,t) + u*e(i,t);
        mismatch_1(i+1,t) = floor(mismatch/2^24); % 截取控制字
    end
end
```

**需要注意的关键点**: 在 `all_cali.m` 中，offset和gain的校准参数在每次迭代中更新，但timing skew的更新频率较低（每完成64通道一次采样后更新），这与PDF文档中描述的分步校准顺序一致。

### 7.2 校准顺序的重要性

校准的顺序至关重要，不可调换：

```
第1步: Offset校准
  原因: 如果存在直流偏移，后续的功率计算（用于增益校准）会引入偏差
  输出: data - offset_estimate
  
第2步: Gain校准
  原因: 增益误差会影响信号幅度，幅度变化会影响自相关计算的准确性
  输出: (1+g') × data
  
第3步: Timing Skew校准
  原因: 时间偏斜不影响幅度和直流偏置，所以放在最后
  输出: 调整后的时钟延迟 → 均匀采样
```

### 7.3 校准效果验证

所有校准脚本都使用 `ADC_dynamic_with_figure` 函数进行"校准前"和"校准后"的对比分析。典型的对比结果：

| 指标 | 校准前 | 校准后 | 改善 |
|------|--------|--------|------|
| SNR | ~25 dB | ~48 dB | +23 dB |
| SFDR | ~35 dBc | ~60 dBc | +25 dB |
| ENOB | ~4 bits | ~7.5 bits | +3.5 bits |

## 8. 性能评估体系：如何衡量校准好坏

### 8.1 `ADC_dynamic_with_figure.m` —— 动态性能测试函数

这是项目中最重要的评估函数，它通过FFT分析计算ADC的关键性能指标。

#### 函数流程

```matlab
function [SNR, SINAD, SFDR, ENOB] = ADC_dynamic_with_figure(ADC_output, fs, dataLen, titleName)
```

**步骤**:
1. **去除直流分量**: `dataFFT = dataFFT - mean(dataFFT)`
2. **加窗处理**: 可选汉宁窗（默认不加窗）
3. **FFT变换**: 计算频谱
4. **搜索基频**: 找到输入信号频率位置
5. **搜索谐波**: 找到2~9次谐波
6. **计算指标**: SNR/SINAD/SFDR/ENOB/THD
7. **绘制频谱图**: 在图上标注关键指标

#### 指标详解

**SNR（信噪比）**:
$$SNR = 10 \log_{10} \left(\frac{P_{signal}}{P_{noise}}\right)$$

衡量信号功率与噪声功率之比。排除谐波分量，只考虑量化噪声、热噪声等。

**SINAD（信纳比）**:
$$SINAD = 10 \log_{10} \left(\frac{P_{signal}}{P_{noise} + P_{distortion}}\right)$$

包含噪声和谐波失真，是更全面的性能指标。

**ENOB（有效位数）**:
$$ENOB = \frac{SINAD - 1.76}{6.02}$$

从SINAD折算出的等效位数。理想的N位ADC能达到N位ENOB，但实际中ENOB总是小于标称分辨率。

**SFDR（无杂散动态范围）**:
$$SFDR = \max(dataSpectdB) - \text{最大杂散功率}$$

衡量信号与最大杂散之间的差距。**这是TIADC校准最直观的指标**——校准前后SFDR的提升最为明显。

**THD（总谐波失真）**:
$$THD = 10 \log_{10} \left(\frac{\sum_{k=2}^{9} P_{harmonic_k}}{P_{signal}}\right)$$

所有谐波总功率与信号功率之比。

### 8.2 频谱分析图中的关键观察

在代码生成的FFT频谱图中（所有校准脚本都会生成）：
- **校准前**: 频谱中能看到明显的杂散峰（位于 $f_s/M$ 的整数倍处）
- **校准后**: 这些杂散被显著抑制，频谱"干净"了很多

### 10.3 改进方向

1. **多档位α自适应切换**: 当前代码多使用单档位，实际硬件中需要实现完整的8档自动切换逻辑
2. **收敛判断模块**: 开发更鲁棒的收敛检测机制，避免过早或过晚切换档位
3. **后台校准**: 当前实现为前台校准（需中断正常数据流），实际系统可能需要后台校准（不中断）
4. **温度补偿**: 温度变化会引起失配漂移，需引入温度感知的重校准机制
5. **盲校准**: 无需已知输入信号的校准技术，适用于实际工作场景

### 10.4 结语

本项目的TIADC校准系统通过**三步递进式校准**，系统地解决了时间交织ADC的三大失配问题。从PDF文档中的数学推导和Verilog硬件设计，到MATLAB代码中的行为级仿真验证，再到最终的FFT频谱分析，形成了一个完整的理论→仿真→验证闭环。

64通道64GSa/s的TIADC系统代表了当前高速数据转换器的前沿技术方向，其校准算法的研究对推动国产高速ADC芯片的发展具有重要意义。
