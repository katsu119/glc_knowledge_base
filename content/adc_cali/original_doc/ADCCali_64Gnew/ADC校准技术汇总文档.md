# 高速 TIADC 校准技术汇总文档

---

## 一、背景介绍

在现代高速数据采集系统中，**模数转换器（ADC，Analog-to-Digital Converter）** 是连接模拟世界与数字世界的核心桥梁。它将连续的模拟信号转换为离散的数字信号，让计算机能够处理、分析和存储真实世界的物理量——比如声音、雷达回波、通信信号等。

随着通信技术（如 5G/6G）、雷达系统和高速示波器的发展，我们对 ADC 采样速率的要求越来越高，动辄数十 GSa/s（每秒千兆采样点）。然而，单颗 ADC 的采样速率受到工艺和功耗的限制，很难做得极高。

那么，如何才能在不牺牲精度的前提下获得超高的采样率呢？

答案是 **时间交织 ADC（TIADC，Time-Interleaved ADC）**。

---

## 二、时间交织 ADC（TIADC）的基本原理

TIADC 的核心思想非常简单——**"众人拾柴火焰高"**。

想象一下：如果你一个人每分钟只能测量 1 次温度，但你想每秒测量 10 次，怎么办？很简单，找 10 个人，让他们轮流测量，每个人每隔 10 秒测一次，但每个人的测量时刻错开 1 秒。这样，整体上你就能做到每秒 10 次的测量频率——这就是时间交织的思想。

在 TIADC 中，我们使用 **M 个低速率子 ADC**，每个子 ADC 以 `fs/M` 的速率采样，但它们的采样时钟在时间上依次错开 `T = 1/fs` 的时间间隔。这样一来，整个系统的等效采样率就达到了 `fs`，是单个子 ADC 的 M 倍。

本项目中研究的是一个 **64 通道、64 GSa/s 的 TIADC 系统**，其基本架构如下：

```
           ┌─────┐  CH1 ──── 子ADC #1
           │     │  CH2 ──── 子ADC #2
  模拟输入 ─▶  时钟  │  ...      ...
    Vin(t)  │ 分配网 │  CH64 ─── 子ADC #64
           └─────┘
         采样时刻依次错开 T = 1/64G ≈ 15.6 ps
```

> 本项目中也包括 **16 通道、16 GSa/s** 的 TIADC 系统方案，原理相同，通道数不同。

## 三、理想很丰满，现实很骨感——失配问题

### 3.1 问题的由来

TIADC 的原理看起来很简单，但现实中的集成电路并非完美。**制造工艺的偏差**会导致各个子 ADC 通道之间存在不一致性，这些不一致性称为 **"通道失配"（Channel Mismatch）**。如果不对这些失配进行校准，TIADC 的输出信噪比会严重劣化，甚至还不如单个子 ADC 的性能。

### 3.2 三种主要的失配类型

本项目针对三种关键的失配类型进行了研究：

#### ① 失调失配（Offset Mismatch）

**是什么？**
每个子 ADC 的输入偏置电压（直流偏移）不完全相同。就像一个体温计，有的人测得总是偏高 0.1°C，有的人总是偏低 0.2°C。

**影响是什么？**
失调失配会在输出频谱中引入位于 **fs/M 及其整数倍频率处**的杂散(spur)，这些杂散就像"幽灵信号"一样出现在频谱中，污染了原本干净的信号。

**数学表达：**
第 k 个通道的失调为 $O_k$，则输出信号中会包含周期为 M 的固定图案噪声。

#### ② 增益失配（Gain Mismatch）

**是什么？**
每个子 ADC 对输入信号的放大倍数（增益）不完全相同。同样是输入 1V 的信号，有的通道输出数字码 127，有的输出 130，有的输出 125。

**影响是什么？**
增益失配同样会在频谱中引入杂散，位置与失调失配类似，但杂散的幅度与输入信号幅度有关——输入信号越大，增益失配引入的杂散越强。

**数学表达：**
第 k 个通道的增益为 $G_k$，理想值为 1。增益误差 $\Delta G_k = G_k - 1$。

#### ③ 时钟偏斜失配（Timing Skew Mismatch）

**是什么？**
这是最棘手的一种失配。理论上，M 个通道的采样时钟应该精确地错开 $T = 1/f_s$ 的时间间隔。但实际电路中，时钟分配网络的不匹配会导致每个通道的实际采样时刻偏离理想位置。

**为什么它最棘手？**
- 对于高频输入信号，微小的时钟偏差会导致巨大的采样值误差。打个比方：在陡峭的山坡上，哪怕脚步位置偏差一点点，高度也会差很多。
- 时钟偏斜引入的杂散与输入信号频率成正比——**输入频率越高，问题越严重**。

**数学表达：**
第 k 个通道的采样时刻为 $t_k = kT + \Delta t_k$，其中 $\Delta t_k$ 即为时钟偏斜误差。引起的误差幅度约为：
$$\epsilon_k \approx A \cdot 2\pi f_{in} \cdot \Delta t_k \cdot \cos(2\pi f_{in} t_k)$$

## 五、ADC 行为模型详解

### 5.1 为什么需要行为模型？

在实际芯片流片（制造）之前，我们需要通过 **行为级模型（Behavioral Model）** 来验证校准算法的有效性。行为模型用软件（MATLAB）模拟 ADC 的量化过程，让我们可以：
- 精确控制各种非理想因素（失配、噪声等）
- 快速迭代算法
- 在投入真实硬件之前验证可行性

### 5.2 非二进制 SAR ADC 模型（ADCF.m）

**什么是非二进制（冗余）ADC？**

传统的二进制 SAR ADC 每一位的权重都是 2 的幂次（128, 64, 32, 16, 8, 4, 2, 1）。而非二进制 ADC 采用 **冗余权重** 设计，权重序列不是严格的 2 的幂次——这样做的好处是给比较器判决错误留出了"纠错空间"。

**本模型的特点：**

该模型是一个 **9 位非二进制 SAR ADC**，其电容权重为：
```
权重 r = [60, 28, 16, 10, 6, 4, 2, 1, 0.5]
输出码字权重 = [120, 56, 32, 20, 12, 8, 4, 2, 1]
```

**工作原理：**

类似于天平称重。系统有两个比较节点：
- **Vp**（正端）= 0.45 - in/2
- **Vn**（负端）= 0.45 + in/2

算法逐位比较 Vn 和 Vp：
1. 如果 Vn ≥ Vp，该位输出 1，下一轮：Vn 减小、Vp 增大（相当于减去参考）
2. 如果 Vn < Vp，该位输出 0，下一轮：Vn 增大、Vp 减小（相当于加上参考）

这个过程反复进行，逐次逼近输入信号的值。

> **关键洞察**：在 `not_2_ADC_calibration` 子目录中的版本，最后一位权重是 1 而不是 0.5，权重序列为 `[60,28,16,10,6,4,2,1,1]`——这是一个微小的变化，可能对应不同的设计迭代。

### 5.3 二进制 SAR ADC 模型（ADCF_2.m）

这是一个通用的二进制 SAR ADC 模型，可以配置：
- **n**: 量化位数
- **FS**: 满量程范围
- **os**: 失调偏移量

**工作原理：**

从最高位（MSB）开始，逐位比较：
```
对于第 i 位：
  如果 input ≥ FS/2^i - FS/2^(n+1)：
    该位输出 1，从 input 中减去 FS/2^i
  否则：
    该位输出 0
```

例如，8 位 ADC 的比较阈值为：`FS/2, FS/4, FS/8, ..., FS/256`。

### 5.4 二进制差分 ADC 模型（ADCF_Binary.m）

这是另一种二进制 ADC 模型，采用 **差分输入**（Vp 和 Vn）架构，更适合模拟全差分 ADC 的行为。其权重为标准二进制：`[64, 32, 16, 8, 4, 2, 1, 0.5]`。

它与 ADCF.m 的区别在于：
- 输入为差分信号（正端 Vp，负端 Vn）而非单端
- 输出为 8 位二进制码，权重为 [128, 64, 32, 16, 8, 4, 2, 1]

## 六、ADC 动态性能评估（ADC_dynamic_with_figure.m）

这是一个至关重要的评估函数，它通过 **FFT（快速傅里叶变换）** 分析 ADC 的输出数据，计算以下关键性能指标：

### 6.1 核心指标解读

| 指标 | 全称 | 含义 | 通俗理解 |
|------|------|------|---------|
| **SNR** | 信噪比 | 信号功率与噪声功率之比 | "你说话的声音有多大，背景杂音有多大" |
| **SINAD** | 信噪失真比 | 信号功率与（噪声+谐波失真）功率之比 | "考虑所有不完美因素后的信号质量" |
| **ENOB** | 有效位数 | 从 SINAD 折算出的等效位数 | "实际精度相当于多少位的理想ADC" |
| **SFDR** | 无杂散动态范围 | 信号与最大杂散之间的功率差 | "信号能比最大的干扰强多少" |
| **THD** | 总谐波失真 | 所有谐波总功率与信号功率之比 | "ADC产生了多少'回声'和'泛音'" |
| **HD(k)** | 第k次谐波失真 | 第k次谐波的功率 | "第k个'泛音'有多强" |

### 6.2 计算公式

- **SINAD** (dB) = $10 \log_{10}\left(\frac{P_{signal}}{P_{noise} + \sum_{k=2}^{9} P_{harmonic,k}}\right)$
- **ENOB** (bits) = $\frac{SINAD - 1.76}{6.02}$
- **SNR** (dB) = $10 \log_{10}\left(\frac{P_{signal}}{P_{noise}}\right)$
- **THD** (dB) = $10 \log_{10}\left(\frac{\sum_{k=2}^{9} P_{harmonic,k}}{P_{signal}}\right)$
- **SFDR** (dB) = $- \max(P_{spur})$

> 其中 1.76 dB 是理想 ADC 的量化噪声理论值，6.02 是每增加 1 位分辨率带来的 SNR 提升（6.02 dB/bit）。

### 6.3 算法流程

1. **数据准备**：截取合适长度的数据段（2 的幂次），去除直流分量
2. **加窗处理**（可选）：使用 Hanning 窗减少频谱泄漏
3. **加入本底噪声**：在信号上加入人工噪声防止频谱过于干净导致图形不真实
4. **FFT 变换**：将时域信号转换到频域，得到幅度谱
5. **寻找基频**：找到最大的频谱分量作为输入信号频率
6. **提取谐波**：依次找到第 1~9 次谐波的位置和功率
7. **计算指标**：根据上述公式计算 SNR、SINAD、ENOB、SFDR、THD、HD

## 七、校准算法详解——核心篇章

这是整份代码的灵魂所在。我们来逐一剖析每种校准算法的设计思路。

---

### 7.1 失调校准（Offset Calibration）

**文件：** `offset_8bits_not2.m`

#### 原理

失调失配表现为各通道输出存在固定的直流偏置差异。校准的核心思想是 **用反馈环路估计并补偿每个通道的失调**。

#### 算法设计

```
对于每次采样：
  1. 对当前通道的输出 Ao 进行累加（低通滤波）
     int(r, i+1) = int(r, i) + w * Ao(r, i)
     其中 w = 2^(-12) 是环路滤波器系数，控制收敛速度
  
  2. 对累加值进行量化（截位），得到补偿量
     int_limit(r, i+1) = floor(int(r, i+1) * 4) / 4
  
  3. 在输入信号中减去估计出的失调量
     Vi_compensated = Vi_original - int_limit / 256
```

#### 控制字累加器（用于监测收敛状态）

代码中还包含一个巧妙的 **"控制字累加器"** 机制，用于监测校准是否已经收敛：

```
跟踪指定通道（第4通道）的补偿值变化方向：
  - 如果补偿值增大 → up_down = 1
  - 如果补偿值减小 → up_down = 0
  - 连续记录 2 次变化方向
  - 若 2 次中"增"和"减"各 1 次（即来回抖动）→ 认为已收敛，计数器 +1
  - 累计 512 次来回抖动 → 输出收敛结果
```

这就像一个"抖动检测器"——当校准值围绕真实值来回抖动时，说明已经收敛到目标附近。

#### 图示验证

校准完成后，代码会绘制每条通道的 **失调估计值随迭代次数的变化曲线**，以及校准前后的频谱对比图。

### 7.2 增益校准（Gain Calibration）

**文件：** `gain_8bits_not2.m`

#### 原理

增益失配表现为各通道对相同输入信号的放大倍数不同。校准的核心思想是 **以所有通道的平均功率为参考，将各通道的增益调整到一致**。

#### 算法设计

```
对于每次采样：
  1. 计算当前通道的输出功率（平方）
     F1(r, i+1) = Ao(r, i)²
  
  2. 计算所有通道的平均功率作为参考
     th_fl(1, i) = round(th(1, i) / 16)
     th(1, i+1) = th(1, i+1) + F1(r, i+1)  ← 所有通道累加
  
  3. 用 LMS（最小均方）算法迭代调整增益控制字
     F3(r, i+1) = F3(r, i) - β * (F1(r, i+1) - th_fl)
     其中 β = 2^(-26) 控制环路带宽
  
  4. 将增益控制字量化为 9 位（乘以 512 后取整）
     F4(r, i+1) = floor(F3(r, i+1) * 512)
  
  5. 在输入信号中应用增益补偿
     Vi_compensated = (1 + F4 * step_size) * G_original * signal
     其中 step_size = 0.05 / 31（6位控制字，调节范围 ±0.05）
```

#### 关键设计点

- **功率检测**：通过 $Ao^2$ 来估计信号功率，避免了乘法器以外的复杂运算
- **平均参考**：所有通道的平均功率作为"黄金参考"，而非固定某个通道——这样可以防止基准漂移
- **LMS 迭代**：梯度下降法的变种，每次沿着误差的负梯度方向微调，逐步逼近最优值

#### 图示验证

校准完成后，代码绘制每条通道的 **有效增益（$G_k \times (1 + step\_size \times F4)$）随迭代次数的变化曲线**，以及校准前后的频谱对比图。

### 7.3 时钟偏斜校准（Timing Skew Calibration）—— 最核心也最复杂

这是整个项目中最具技术深度的部分。项目中包含了多个版本的实现，我们逐一分析。

#### 7.3.1 基本原理

时钟偏斜校准的核心思想是：**利用相邻通道输出之间的相关性来估计时间偏差**。

想象一下：如果两个相邻通道的采样时刻完全正确（没有偏斜），它们各自采样值的乘积的统计平均值（即互相关）应该等于某个预期值。如果存在偏斜，互相关值会发生偏移——通过测量这种偏移，就能反推出偏斜量。

**关键观察：** 对于同一个输入信号，相邻通道的采样值满足：
$$E[Ao_k \cdot Ao_{k+1}] \propto R(\Delta t)$$
其中 $R(\cdot)$ 是输入信号的自相关函数。当 $\Delta t = 0$ 时，相关值达到最大（对于低频信号）或特定值（对于正弦信号）。通过比较各通道的相关值与平均相关值的差异，就可以估计出偏斜误差。

#### 7.3.2 版本一：`time_loop.m`（16通道，经典互相关法）

这个版本采用 **全局互相关+误差平均** 的方法：

1. 对每对相邻通道的输出做互相关：$I_k = Ao_k \cdot Ao_{k+1}$
2. 计算当前时刻所有通道互相关的平均值：$avg = mean(I_k)$
3. 以通道 1 为参考（假设其无偏斜），计算各通道互相关与平均值的偏差作为误差信号
4. 用 LMS 算法更新偏斜估计：$\Delta t_k^{(i+1)} = \Delta t_k^{(i)} - u \cdot error_k$
5. 步长 $u = 2^{-70}$ 非常小，确保收敛稳定性

**为什么步长这么小？** 因为时钟偏斜的量级是皮秒（$10^{-12}$）级，估计算法的精度必须非常高。

#### 7.3.3 版本二：`time_not2.m`（64通道，分组互相关法）

这个版本针对 **64 通道、64 GHz** 系统，将通道分为 4 组（每组 16 个通道共用同一路 16 GHz 子时钟），只需要校准 4 个时钟偏斜值。

**分组思路：**
- 64 个通道由 4 路 16 GHz 时钟驱动
- 每路时钟驱动 16 个通道（通道 1,5,9,...,61 共用时钟1；通道 2,6,10,...,62 共用时钟2；以此类推）
- 因此只需要估计和补偿 **4 个偏斜参数**

**互相关计算：**
```
对于每组相邻通道（间隔4）：
  A1 = Ao(1)*Ao(2) + Ao(2)*Ao(3) + Ao(3)*Ao(4)   ← 时钟1×时钟2的相关
  A2 = Ao(4)*Ao(5) + Ao(5)*Ao(6) + Ao(6)*Ao(7) + Ao(7)*Ao(8)   ← 时钟2×时钟3
  ...
  累计所有互相关值得到 A17
```

**误差计算：**
```
对于每个待校准的时钟偏斜（t=2,3,4）：
  对 16 对相邻通道累加互相关
  e(t) = -Σ[Ao(t-1+4m) × Ao(t+4m) / s] × 4 + A17
  mismatch(t+1) = mismatch(t) + u × e(t)
  mismatch_1(t+1) = floor(mismatch(t+1) / 2^24)  ← 截位以控制字输出
```

其中：
- `s` 是截尾因子，控制相关值的大小范围
- `u = 2^9` 是环路增益
- `step_size = 10^(-14)` (10 fs) 是最小可调步长
- 截位操作 `/2^24` 将累加值映射到可实现的数字控制字

#### 7.3.4 版本三：`time_not2_1.m`（二进制 ADC 版本）

与 `time_not2.m` 基本相同，但：
- 使用二进制 ADC 模型 (`ADCF_2`)
- 增加了直流偏置（+0.45）
- 输入幅度参数化为变量 `amplitude`
- 对累加值的截位策略不同（`mismatch_1(i+1,t) = floor(mismatch(i+1,t)/2^30)`，保留更多精度）

#### 7.3.5 版本四：`time_onlyone.m`（简化版）

这是一个测试性质的简化版本：
- 只计算前 8 个通道的互相关
- 每个待校准时钟只考虑一对相邻通道
- 步长 $u = 2^{-30}$（不同于其他版本的 $2^9$）

这种简化可能用于快速验证算法可行性，但在实际应用中精度可能不足。

### 7.4 综合校准（All-in-One Calibration）

**文件：** `all_cali.m`

这是整个项目的集大成者——**同时进行失调、增益和时钟偏斜三种校准**。

#### 算法流程

对于每次采样（以 64 通道为一组）：

```
1. 生成带误差的输入信号
   Vi(i,t) = (1+gain_cw) × G_k × A × cos(ωt + φ + skew - Δt) + O_k - offset_comp

2. 通过 ADC 量化
   Ao(i,t) = ADCF(Vi(i,t)) - 128

3. 增益校准更新
   gain_f1 = Ao²
   gain_f3 = gain_f3 - β × (gain_f1 - th_fl)
   gain_f4 = floor(gain_f3 × 512)

4. 失调校准更新
   int = int + w × Ao
   int_limit = floor(int × 4) / 4

5. 时钟偏斜校准更新
   计算各通道组间互相关
   计算误差信号 e
   mismatch = mismatch + u × e
   mismatch_1 = floor(mismatch / 2^24)
```

#### 校准参数配置

| 参数 | 值 | 含义 |
|------|-----|------|
| `gain_step_size` | 0.05/31 | 增益控制字步长（6位，±0.05范围） |
| `time_step_size` | $10^{-14}$ s | 时间偏斜最小可调步长（10 fs） |
| `β` (beta) | $2^{-23}$ | 增益 LMS 环路带宽控制 |
| `w` | $[2^{-10}, 2^{-11}, 2^{-12}, 2^{-13}, 2^{-14}, 2^{-15}]$ | 失调校准滤波器系数 |
| `u` | $2^9$ | 时钟偏斜校准环路增益 |
| `s` | 16 | 互相关截尾因子 |

## 八、深入理解校准算法的设计哲学

### 8.1 为什么大多数校准采用"背景校准"？

本项目中所有的校准算法都是 **背景校准（Background Calibration）**——在校准过程中，ADC 仍然在正常采样工作，无需中断数据采集。

这与 **前台校准（Foreground Calibration）** 相对：前台校准需要中断正常操作，注入已知测试信号进行校准。背景校准的优势在于：
- 不影响系统正常工作
- 可以持续跟踪温度、电压变化引起的漂移
- 对于雷达、通信等不能中断的应用至关重要

### 8.2 LMS 算法为何如此流行？

LMS（Least Mean Squares，最小均方）算法在本项目中多次出现（增益校准、时钟偏斜校准）。它的魅力在于：

1. **计算简单**：只需要乘法和加法，适合硬件实现
2. **无需统计先验知识**：自适应地找到最优解
3. **鲁棒性强**：对信号模型误差不敏感

其核心迭代公式为：
$$\theta^{(n+1)} = \theta^{(n)} - \mu \cdot \nabla J(\theta^{(n)})$$
其中 $\mu$ 是步长，$\nabla J$ 是代价函数的梯度。

### 8.3 截位（Floor/Quantization）的艺术

代码中多处出现 `floor()` 操作，这是 **数字电路实现的必然要求**。在硬件中：
- 累加器有有限的位宽
- 控制字必须是整数
- 补偿值必须量化到可实现的最小步长

因此，算法设计中**必须考虑量化效应**对收敛精度和稳定性的影响。

### 8.4 为什么增益校准需要功率参考？

增益校准不能直接用输出电压除以输入电压来估计增益，因为我们对真实的输入电压并不完全确定（有噪声、有失调等干扰）。

一个巧妙的方法是使用 **信号功率** 作为统计量：
- 各通道的信号功率的**长期统计平均值**反映了增益的差异
- 用所有通道的平均功率作为"共识参考"——因为平均值的期望就是真实功率

### 11.1 已实现的核心能力

本项目围绕 **高速时间交织 ADC 的通道失配校准** 这一核心问题，实现了以下关键技术：
