\section{妙妙想法记录}

\begin{ideabox}
  \textbf{墨水瓶 GPS 导航车机} —— 使用 Sharp Memory LCD（墨水屏技术）制作车载 GPS 导航设备。墨水屏在阳光直射下依然清晰可见、不反光、超低功耗。可实时显示地图导航信息、路线指引、速度、剩余里程等关键数据。适合摩托车、自行车等户外场景。
\end{ideabox}

\begin{ideabox}
  \textbf{VIVO 表盘 · 随身记录器} —— 开发一个 VIVO 手表表盘应用，具备以下功能：
  \begin{itemize}
    \item \textbf{实时录音}：持续或按需录制环境音频；
    \item \textbf{AI 每日分析}：每天自动将录音上传至云端 AI 进行分析，生成当天活动摘要；
    \item \textbf{GPS 轨迹追踪}：实时获取 GPS 数据，记录一天中去过的地点、路线、停留时间；
    \item \textbf{综合日报}：结合语音记录（说了什么/听到了什么）和位置轨迹（去了哪里/做了什么），生成一份完整的"每日生活记录报告"。
  \end{itemize}
  相当于一个随身佩戴的自动日记助手。
\end{ideabox}

\begin{ideabox}
  \textbf{宠物店周末零工} —— 周末或空闲时间去宠物店打零工，给狗洗澡、剪毛、烘干、打扫。好处：
  \begin{itemize}
    \item \textbf{身心解压}：跟动物打交道是天然的情绪调节，比刷手机强；
    \item \textbf{技能积累}：宠物美容是手艺活，不同犬种毛质、剪法、应激处理都有门道，以后养狗省美容费；
    \item \textbf{额外收入}：周末零工日结几百，现金流可观；
    \item \textbf{体力活}：大型犬（金毛、阿拉斯加）洗一次跟打一架似的，权当健身。
  \end{itemize}
  注意事项：通常从打扫、遛狗、烘干做起，不会一上来就让动剪刀；部分狗脾气暴，需戴嘴套防咬。
\end{ideabox}
